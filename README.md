# ia.juanjeojeda.com

Artículos y notas sobre agentes de IA, sistemas de memoria, aprendizaje y sistemas complejos.

Versión en español de [ai.juanjeojeda.com](https://ai.juanjeojeda.com).

Construido con [Quartz](https://quartz.jzhao.xyz/).

## Desarrollo local

```bash
npm i
npx quartz build --serve
```

El sitio se abre en http://localhost:8080.

## Deploy

Push a `main` dispara GitHub Actions → GitHub Pages.
